Subdomain Takeover - Proof of Concept

Authorized Security Research & Penetration Testing

CONFIDENTIAL
⚡ This is a controlled security test.
This page demonstrates that the subdomain ff-roadmap.adobe.com was vulnerable to subdomain takeover due to an unclaimed GitHub Pages configuration.

📋 Technical Details

Target Domain: ff-roadmap.adobe.com
Vulnerable Service: GitHub Pages
DNS Record Type: CNAME → *.github.io
HTTP Status: 404 Not Found (before takeover)
Server Header: GitHub.com
Discovery Date: September 29, 2026
Researcher: Muhammad Khalid Bin Walid

🎯 Potential Impact

  • Phishing Attacks: Serve fake Adobe login pages to steal credentials
  • Malware Distribution: Host malicious downloads under trusted domain
  • Brand Damage: Reputation harm from malicious content on Adobe domain
  • Data Theft: Intercept sensitive information from users
  • Cookie Hijacking: Potentially access session cookies if shared across subdomains
✅ Remediation Status:
This proof of concept has been created solely for demonstration purposes. The researcher recommends immediate removal or proper configuration of this DNS record.
